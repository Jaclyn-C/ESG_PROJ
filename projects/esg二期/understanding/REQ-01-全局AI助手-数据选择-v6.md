## 1. 背景与目标

平台现有「全局 AI 智能助手」（悬浮对话窗口，客户需求文档 6.2，状态【开发中】），已具备三种模式（智能问答 / 报告生成 / 指标信息采集表）以及文字输入、📎 本地附件上传、【🗂】知识库引用等输入方式。本需求在该助手中新增「数据选择」功能：用户按指标层级逐层下钻（或搜索）选定指标；**每个已选指标各自配置年份与维度**，维度支持**跨维度多选**（同一指标可同时按 分会/法人/策进组 等不同维度圈定多个对象），以「指标名 + 层级 + 该指标自己的年份 + 该指标自己的跨维度对象」确定具体的数据；一次性提交后由 AI 以单个表格返回查询结果（选择与返回一一对应、无累加），表格支持**全屏**查看；维度选择弹窗提供**选中可视化**（着色选中态＋按维度着色的已选总览 chips）。

指标层级共 5 层，参照截图（`inputs/screenshots/`）：
- **image1.png**＝指标库列表（第 1 层）：列为 # / 指标库 / 是否有效 / 指标库详情（配置）/ 操作（编辑、删除）；共 7 个指标库（含 2 个「无效」旧库）。**本功能第 1 层仅显示 5 个「有效」指标库：E维度/S维度/G维度/SC/O维度指标库。**
- **image2.png**＝指标库详情：内部四层结构 **维度 → 主题 → 议题 → 指标**（示例树：环境（维度）→ 环境政策与管理体系（主题）、能源（主题）→ 各自议题 → 指标）；右侧表格含 指标代码（格式如 E-E-14-1-0001）/ 指标名称 / 指标描述 等。**本功能在指标层仅取 指标代码 + 指标名称 两个字段展示。**

维度选项 mock 来源（三张系统管理页截图，详见第 9 节附录）：`分会.png`（13 项扁平列表）、`法人.png`（10 项，法人代码+法人名称）、`策进组（包含策进组的二级组织）.png`（两级：3 个策进组＋各二级组织）；FII 仅 1 个选项「FII」。

与现有全局规则的衔接：
- **全局规则 1（AI 标注）**：「数据选择」本身是用户主动选择行为；AI 返回的查询结果表格（含全屏视图）属 AI 生成内容，须按现行 AI 标注规则执行（"⚠ AI生成/提取，请人工核实"）。
- **全局规则 6（AI 权限可见性）**：本功能**不考虑任何权限**（不做权限过滤，9/7 用户拍板）；该决定**不写入开发需求文档**（仅 REQ 记录供内部追溯，见第 8 节 B 补记）。
- **全局规则 7（Agent 功能按角色开放）**：【数据选择】与【报告生成】【指标信息采集表】一致，**仅对管理员可见**（v2 用户拍板）。

## 2. 功能点

- **FP-1 【数据选择】按钮（仅管理员）**：位于助手输入区上方的模式/功能按钮区，排在【指标信息采集表】之后；仅管理员可见，普通用户不显示该按钮（参照全局规则 7 先例：无对应模式与提示）。完成标志：管理员能在按钮区看到并点击【数据选择】。
- **FP-2 五层下钻选择**：指标库（第 1 层）→ 维度（第 2 层）→ 主题（第 3 层）→ 议题（第 4 层）→ 指标（第 5 层）；未选指标库不能选下层；指标层列表项仅显示 指标代码 + 指标名称。完成标志：用户能从指标库一路下钻到指标并勾选。
- **FP-3 子树搜索**：在当前停留层级可搜索该层级节点子树内的所有指标（跨下级直达），停留越深范围越窄；仅匹配指标名称。**搜索仅作用于指标，不扩展到维度选项**（维度二级弹窗不提供搜索，9/7 定稿）。完成标志：输入关键词返回子树内名称匹配的指标并可选中。
- **FP-4 多选与批量提交（指标级口径）**：指标可多选；**每个指标各自携带其年份与跨维度配置**一次性提交；未做任何配置的指标按默认值（当年＋FII）提交。完成标志：一次提交一组各带自身年份/维度口径的指标查询。
- **FP-5 结果表格一次性返回（一一对应，无累加）**：AI 对话框对本次提交的全部指标**一次性**返回查询结果，以**一个表格**承载；**行构成＝选择与返回一一对应（无累加）**：每个所选维度对象对应一条数据；同一指标选 N 个对象（同维度内或跨维度）＝N 行，每行为经该维度从数据库取到的一条数据；无数值加总、无合并/汇总行；策进组一级＝1 行，不展开不求和；维度未选的指标按 1 个默认对象 FII 计；每个指标行的年份列、维度对象列取该指标各自的配置；**维度对象列＝单列定稿（9/7 拍板）**：单元格显示「维度名 · 对象名」（如「分会层级 · CESBG」）以区分所属维度，不拆两列；**列集与列序定稿（9/7 拍板，按现状）：指标代码 / 指标名称 / 年份 / 维度对象 / 数值 / 单位（此顺序，无数据来源列）**；**指标无查询结果时保留该行、数值列以「—」占位（9/7 定稿）**。完成标志：会话中出现承载本次全部提交指标结果的单一表格。
- **FP-6 指标级年份选择**：已选指标区内，**每个已选指标条目内**各自提供年份选择（默认口径：年份下拉，mock 年份范围取近年若干年）；**可选可不选，不选默认当年（当前＝2026）**；各指标年份可互不相同。完成标志：年份按指标各自生效，未选时该指标按当年处理。
- **FP-7 指标级维度选择（跨维度多选＋选中可视化）**：**每个已选指标条目内**各自提供【维度选择】入口，点击弹出二级弹窗，**弹窗内四个维度的选项可跨维度累计勾选**——同一指标可同时选 FII＋分会层级若干对象＋法人层级若干对象＋策进组层级若干对象（**四维度全部可共存，不互斥**；每个维度内仍多选）；法人选项显示 法人代码＋法人名称；策进组两级——可只勾选一级策进组（＝覆盖该组、不选二级组织），也可勾选二级组织；FII 为整体口径；**可不选，全部不选时默认 FII**；确认结果只落到当前配置的这个指标上，条目内回显跨维度汇总（如「分会×2、法人×1、策进组×1」），可清除。**选中可视化**：① 页签内已勾选行显示着色选中态（高亮底色＋勾选标记，与主选择弹窗选中行样式一致）；② 弹窗内「已选对象」总览区以彩色 chips 展示全部已选对象——按所属维度着色（FII/分会/法人/策进组各一色），chip 文字含维度与对象名，可单独【✕】移除，随勾选实时刷新、跨页签可见；③ 页签数量角标保留。完成标志：每个指标能独立跨维度圈定对象；任意时刻在页签内与总览区都能看清已选内容并能移除；未选时该指标按 FII 处理。
  - **FII 可与其他维度混选（9/7 拍板，推翻原「互斥」默认口径）**：四个维度之间、维度内之间都可多选，所有选择都不互斥——FII 可与分会/法人/策进组对象同时勾选、同时生效（例：同时勾 FII＋分会·CESBG＋法人·某法人＝3 行：FII 整体 1 行＋CESBG 1 行＋该法人 1 行，仍一一对应、无累加）；唯一保留的默认：**全部不选**时按 FII 整体口径查询（该指标 1 行）。
- **FP-8 结果表格全屏**：指标数据查询结果卡片的表格提供【全屏】按钮；点击后该表格**全屏展示**；全屏内容＝该卡片内的表格本身（表头、全部行，列集同 FP-5：指标代码/指标名称/年份/维度对象/数值/单位），保留「⚠ AI生成/提取，请人工核实」标注与表脚注记；全屏实现方式＝**覆盖层**（9/7 定稿，现状）；退出＝【✕】按钮或 ESC。完成标志：任一结果表格可进入与退出全屏，内容与卡片内表格一致。

## 3. 交互流程（点击级）

> 界面形态默认口径（可改）：数据选择为**主弹窗**；维度选择为**叠在其上的二级弹窗**，风格对齐现有弹窗（如【🗂】知识库选择弹窗）。**年份与维度不在全局条件行，而在每个已选指标条目内**（v4 纠正确立）；**维度为跨维度多选**（v5 变更一）；**多选返回一一对应、无累加**（v5 9/7 澄清）。

### 流程 A：五层下钻、已选区逐指标配置、提交（对应原型位置：全局 AI 助手 widget · 输入区上方按钮区 + 数据选择弹窗）

1. 管理员用户在平台任一页面右下角打开全局 AI 智能助手（沿用 6.2.1 既有交互）。普通用户：输入区上方按钮区不出现【数据选择】按钮。
2. 助手输入区上方的模式/功能按钮区（现有【报告生成】【指标信息采集表】等）中，【指标信息采集表】之后显示【数据选择】按钮。
3. 管理员点击【数据选择】，弹出数据选择弹窗。
4. 弹窗展示第 1 层「指标库」列表：仅显示 5 个「有效」指标库——E维度指标库、S维度指标库、G维度指标库、SC指标库、O维度指标库（2 个「无效」旧库不显示）。
5. 未选择指标库时，不能选择下层内容。
6. 选定某个指标库后，显示该库的维度列表（第 2 层）。**原型 mock：无论选择哪个指标库，下钻内容都复用同一棵 环境→主题→议题→指标 树**（环境维度下含 环境政策与管理体系、能源 等主题，与 image2 一致）。
7. 选择某维度后，显示其下主题列表（第 3 层）；选择某主题后，显示其下议题列表（第 4 层）；选择某议题后，显示其下指标列表（第 5 层，即 image2 右侧表格中的指标）。
8. 指标层列表项仅显示两项信息：指标代码 + 指标名称（如 `E-E-14-1-0001 能源消耗总量`）；不显示指标描述、维度/主题/议题归属等其他字段。
9. 用户勾选指标，可勾选多个（多选）。
10. 每个勾选的指标进入弹窗内**已选指标区**，成为一条**可配置条目**；条目信息：指标代码＋指标名称，以及该指标自己的 ① 年份选择 ② 【维度选择】入口 ③ 移除操作。
11. 用户在条目内各自配置：**年份**（默认口径：年份下拉，mock 近年若干年；可不选，不选默认当年，当前＝2026）；**维度**（点击条目内【维度选择】进入流程 C，**可跨维度累计勾选**多个对象，确认结果只落到当前条目并回显跨维度汇总，如「分会×2、法人×1、策进组×1」；可不配置，不选默认 FII）。不同条目可互不相同。
12. 条目可移除；移除时该指标的年份/维度配置随之丢弃。
13. 用户提交（一次提交全部已选指标，每个指标携带各自年份与跨维度对象；不做任何配置＝全部按 当年＋FII；提交按钮命名与位置随原型定）。
14. AI 对话框**一次性**返回查询结果：以**一个表格**承载，行构成＝选择与返回一一对应——每个所选维度对象对应一条数据；同一指标选 N 个对象（同维度内或跨维度）＝N 行，无数值加总、无合并/汇总行；策进组一级＝1 行，不展开不求和（例：同一指标选 3 个不同维度对象即显示 3 行该指标，每行是经不同维度从数据库取到的一条数据——用户口述例证）；年份列/维度对象列按各指标各自配置，维度对象列＝单列，显示「维度名 · 对象名」（9/7 拍板定稿，不拆两列）；列集与列序见 FP-5（9/7 定稿）；指标无查询结果时保留该行、数值列显示「—」（9/7 定稿）；带 AI 标注。

### 流程 B：子树搜索（与流程 A 并用，作用于当前停留层级）

1. 用户下钻至任一层级（如主题层）时，在搜索框输入关键词。
2. 系统在**当前停留层级节点的子树内**检索所有指标（跨下级直达）：停在主题层即可搜到该主题下所有指标；停留层级越深，检索范围越窄；无匹配结果时显示「暂无匹配指标」（9/7 定稿）。
3. 仅匹配**指标名称**，不匹配指标代码。
4. 用户在搜索结果中勾选目标指标，效果与逐层勾选相同（同样进入已选指标区成为可配置条目），可多选、可一并提交。
5. 搜索仅作用于指标选择，不覆盖年份与维度选项；**维度二级弹窗不提供搜索（9/7 定稿）**。

### 流程 C：维度选择（二级弹窗 · 跨维度累计勾选＋选中可视化；入口与落点＝当前配置的指标条目）

1. 用户在**某条已选指标条目内**点击【维度选择】，弹出二级弹窗（叠在数据选择弹窗之上，弹窗保持打开；风格对齐现有弹窗）。
2. 弹窗提供四个维度的页签/选项区：FII / 分会层级 / 法人层级 / 策进组层级，**页签带数量角标**（显示该维度已选对象数，角标保留）；**跨维度累计勾选**：不切换作废——在同一指标上可同时勾选 FII＋分会层级若干＋法人层级若干＋策进组层级若干（四维度含 FII 全部可共存，不互斥），每个维度内仍多选。
3. **分会层级**：单层列表，选项为各分会（mock 13 项，见第 9 节附录），可多选。
4. **法人层级**：单层列表，选项为各法人（mock 10 项，每项显示 法人代码＋法人名称），可多选。
5. **策进组层级**：两级结构——可直接勾选一级策进组（E策进组 / S策进组 / G策进组，＝覆盖该组、不限定二级组织）；也可勾选其下二级组织（如 E1气候行动…，mock 见附录），可多选；允许只选一级、不选二级。
6. **FII**：仅 1 个选项「FII」，**可与其他维度的对象同时勾选、同时生效**（不互斥；例：同时勾 FII＋分会·CESBG＋法人·某法人＝3 行：FII 整体 1 行＋CESBG 1 行＋该法人 1 行，一一对应、无累加）；唯一保留的默认：**全部不选**时按 FII 整体口径查询（该指标 1 行）。
7. **页签内选中态**：已勾选对象的行显示明显着色选中态——高亮底色＋勾选标记，与主选择弹窗选中行样式一致；切换到其他页签再切回，选中态保持可见。
8. **跨维度已选总览区**：弹窗内提供「已选对象」总览区——每个已选对象一枚彩色 chip，**按所属维度着色**（FII/分会/法人/策进组各一色），chip 文字含维度与对象名（如「分会 · CESBG」「法人 · 富联科技(晋城)」）；随勾选**实时刷新**，**跨页签可见**（当前页签看不到的已选对象也在此呈现——解决「切走页签看不到选了什么」）。
9. **chip 移除**：点某枚 chip 上的【✕】单独移除该对象，对应页签内该行取消选中、角标数字减一，总览区同步刷新。
10. **可不选**：该指标不勾选任何维度对象时，默认 FII；确认后关闭二级弹窗，**选择结果只落到当前配置的这个指标条目**：条目内回显跨维度汇总（如「分会×2、法人×1、策进组×1」），可清除；清除后该指标回到默认 FII。其他指标条目不受影响。

### 流程 D：结果表格全屏（会话区 · 查询结果卡片）

1. 查询结果卡片内的表格提供【全屏】按钮。
2. 用户点击【全屏】，该表格进入全屏展示（**覆盖层全屏，9/7 定稿**）。
3. 全屏内容＝该卡片内的表格本身：表头＋全部行（列集同 FP-5：指标代码/指标名称/年份/维度对象/数值/单位，无数据来源列），保留「⚠ AI生成/提取，请人工核实」标注与表脚待确认注记。
4. 用户点击【✕】或按 ESC 退出全屏，回到会话区原位（表格内容与状态不变）。

## 5. 状态与边界

| 场景 | 表现 |
|---|---|
| 普通用户（非管理员） | 不显示【数据选择】按钮（参照全局规则 7 先例：无对应模式与提示） |
| 未选指标库 | 不能选择下层内容（必须先选指标库） |
| 条目年份未选 | 该指标按当年（当前＝2026）查询，结果行年份列按当年展示 |
| 条目维度未选 / 已清除 | 该指标按默认 FII：结果中该指标按 1 个默认维度对象「FII」展开 |
| 同一提交中不同指标配置不同 | 允许：各指标年份/维度互不相同，各行按各自配置返回 |
| 同一指标跨维度对象共存 | 允许：一次提交中同一指标可携带多个维度（含 FII）的多个对象，各对象各出一行；所有选择都不互斥、可任意组合勾选（9/7 拍板："所有选择都不互斥"） |
| 多选数据语义（无累加） | 选择与返回一一对应：同维度内或跨维度多选 N 个对象＝N 行各自数据，无数值加总、无合并/汇总行；策进组一级＝1 行，不展开不求和（9/7 用户澄清："无论是跨维度多选，还是维度内的多选，都不需要累加，选择什么就返回什么"） |
| 维度页签切换 | 已选状态保持：切走再切回，行选中态、页签角标、已选总览 chips 均不丢失 |
| 移除已选对象 chip | 仅移除该对象：对应页签行取消选中、角标减一，其他已选对象与总览区不受影响 |
| 移除指标条目 | 该指标的年份/维度（含全部跨维度对象）配置随之丢弃（不可恢复） |
| 策进组只勾选一级 | 该指标口径＝该策进组整体（不限定二级组织），计 1 个对象 |
| 全屏中退出 | 【✕】或 ESC 退出全屏，回到会话区原位，表格内容不变 |
| 搜索无匹配结果 | 显示「暂无匹配指标」（9/7 定稿） |
| 指标库/指标/维度数据加载中 | 待确认 |
| 数据加载失败 | 待确认 |
| 权限过滤 | 本功能不考虑任何权限：不对指标/维度对象做权限过滤（9/7 拍板）；此决定不写入开发需求文档（仅本 REQ 记录供内部追溯） |
| 提交的指标无查询结果 | 保留该行，数值列显示「—」（9/7 定稿） |
