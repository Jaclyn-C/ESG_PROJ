# inputs/ 素材投放指南（放完文件后可删掉本说明）

| 文件类型 | 放到哪 | 命名 |
|---|---|---|
| 原始需求文档（客户的 Word/PDF/邮件导出/聊天记录截图等） | `inputs/` 根目录 | 加序号前缀：`01-xxx.pdf`、`02-xxx.docx`，**序号 = agent 阅读优先级**，重要的排前面 |
| 现有系统/产品的页面截图（原型要照着画内容的） | `inputs/screenshots/` | 随意，能认出是哪个页面即可 |
| 风格参考（喜欢的界面截图、设计规范） | `inputs/style-refs/` | 随意 |

- screenshots 和 style-refs 的区别：**screenshots = 原型的内容基础**（页面结构照它来），**style-refs = 原型的视觉基准**（配色/风格照它来）。
- 本目录对 agent 是**只读**的——这里只放原始素材，不要在这里改内容。
