# PM-workflow — 产品经理 AI 工作台

把口述需求变成四类资产：**需求理解（唯一事实源）→ 三件套（客户确认说明 PDF / 开发需求文档 / 交互原型）**，外加汇报 PPT、调研报告、工作日志（日报/周报）。

- 总规则与流程：[CLAUDE.md](CLAUDE.md)
- Agent 团队：`.claude/agents/`（7 个角色）
- 文档模板：`templates/`
- 项目归档：`projects/<项目名>/`（结构说明见 `projects/_template/README.md`）

## 第一次使用

1. **用 Claude Code 打开本文件夹（PM-workflow/）作为工作区根目录**——`.claude/agents/` 只有在根目录打开才会加载；
2. 开新项目：直接说「新建项目：XX」，主对话会建好目录骨架并初始化状态文件；
3. （可选，生成客户 PDF 需要）安装 LaTeX 编译器：`brew install tectonic`。不装也能用，确认说明会以 .tex 源文件交付。

## 日常口令速查

| 你说 | 发生什么 |
|---|---|
| 「客户想要一个……（随意描述）」 | product-agent 澄清反问 → 出需求理解 v1 给你确认 |
| 「出三件套」 | 同步生成：确认说明 PDF + 开发需求文档 + 交互原型 |
| 「客户改了：……」 | 需求理解升 v2 → 受影响产物重出 |
| 「给我看现在全部需求」 | 生成需求总览快照 |
| 「收工 / 记一笔」 | worklog-agent 记会话记录 + 刷新 status.md |
| 「今天总结 / 出周报」 | 汇总日报 / 生成周报 |
| 「做一份 PPT，方向是……」 | ppt-agent 先出大纲确认，再成片（仅点名触发） |
| 「调研一下 XX 竞品」 | research-agent 联网调研（只带公开关键词，不带客户内容） |
| 「切到 XX 项目」 | 切换当前项目上下文 |

## 你要动手的只有两件事

1. 素材放进对应项目的 `inputs/`（原始需求文档名前加序号 01-、02- 表示阅读顺序；页面快照进 `screenshots/`，风格参考进 `style-refs/`）；
2. 每轮工作结束说声「收工」打卡——忘了也没关系，下次会话会根据文件变化提醒你补记。

## 改东西的规则速查

- 功能/交互/数据变了 → 对话里说（走需求理解升版，产物重派生）；
- 错字措辞微调 → 直接改文件，回头说一句同步进需求理解；
- 原型 → 随便改，手改会被继承。

## 产物去向

```
projects/<项目名>/
├─ understanding/REQ-01-名称-v2.md   ← 需求理解（唯一事实源，永远只有最新版）
├─ outputs/confirm/                  ← 功能确认说明 .tex/.pdf（交客户）
├─ outputs/dev-spec/                 ← 开发需求文档 .md（交开发，含验收清单）
├─ outputs/prototype/v2/index.html   ← 交互原型（浏览器打开演示）
├─ outputs/ppt/v1/                   ← 汇报幻灯片（浏览器 F11 放映，可打印成 PDF）
├─ worklog/2026-09-04.md             ← 工作日志（日报原料）
├─ status.md                         ← 当前状态快照（新会话开场必读）
└─ archive/                          ← 历史旧版本
```
